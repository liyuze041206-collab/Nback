# GSPM-Net 网络架构介绍

双击 `start.bat` 启动，或在现有服务运行时打开 http://127.0.0.1:8000/architecture.html 。

- 首页按 `整体架构.pptx` 的 A / B / C / D 组织，全图为 HTML / CSS / SVG 元素，没有嵌入架构截图。
- 七个总览小图各有不同操作特征；点击节点进入 16 个独立图解。连续波形与处理后分窗、行门控与列门控、概率平滑与状态转移均分别表达。浏览器前进后退、模块导航、Escape 返回总览可使用。
- 右上角设置菜单切换网络原理、EEG 分类，统一设置深浅主题和动效。首次动效遵循系统减少动态效果设置，保存后使用用户偏好。手机采用换行布局。
- 详情图框、图例及输入输出位置保持稳定，共同图形保留，仅变化组件使用 260ms 过渡；快速切换取消旧过渡，关闭动效立即显示最终状态，没有新增自动循环或播放按钮。
- 说明依据项目原版论文 § III B–E、图 1–2；示意波形不是实测预测。每类 20 个支持窗口按 7 / 7 / 6 分配至三个 session。
- 按最新界面要求，网页不显示参考行、底部论文说明和示意/非实测提示；研究来源在本地文档保留，图形、公式及功能说明继续显示。

源文件为 `gspm_network_atlas.html`，绘图实现为同目录 `gspm_diagrams.js`，也可以直接用浏览器离线打开。离线分发需同时保留这两个文件、共享样式/设置及 assets。直接打开不启动 EEG 分析服务，实际分类请使用启动入口。

维护：`frontend` 中执行 `npm run build` 会先同步架构页到 `public/architecture.html`，再输出至 `dist`。`node qa-atlas.mjs` 在本机服务上检查 16 个模块、双向跳转、键盘操作、响应式布局、减少动效和离线打开，截图保存在本目录。

`node qa-diagram-transitions.mjs` 检查独立图解、稳定框架、共同节点保留、260ms 动画、快速切换及动效关闭，截图在 `docs/module-diagrams`。本轮记录见 `docs/VALIDATION.md`。

旧版独立页面和历史备份已清理，当前平台使用项目根目录的页面源码。
