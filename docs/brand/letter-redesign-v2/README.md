## 深色预览提示词

Use case: logo-brand. Asset type: a polished design preview board for GSPM-Net architecture section markers. Design exactly four matching square section badges, labeled with the exact single capital letters A, B, C, D in that order. New aesthetic: restrained premium scientific interface, precise geometric sans-serif medium-bold letterforms, upright and optically centered, rounded squares with modest corner radius, ONE tiny horizontal pale-gold accent near the lower right rim of each square. Perfect consistent construction, weight, spacing and baseline across all four. No sculptural chrome, no thick bevels, no crystalline facets, no huge glow, no italics, no decorative neural drawings, no stars. Wide landscape preview board: four large approximately 100px badge samples in one clean centered row with generous even spacing; beneath them, a second row repeats the exact same four badges much smaller at realistic approximately 32px UI size. No captions, no titles, no text other than these two A B C D rows. Flat front-on graphic design, clean edges and deliberate negative space. DARK THEME VARIANT: solid very dark navy #060d1b board background. Each badge has a subtle translucent smoky navy-blue surface and a thin cool blue border; the letter is matte ice-blue #d5e9ff with almost flat treatment. Very gentle inner blue lighting restricted to the square edge, no outer glow. Tiny muted pale-gold rim tick. Refined quiet technical feel. Legibility at 32px is paramount.
